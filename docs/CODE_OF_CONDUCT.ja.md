# 行動規範

[English](../CODE_OF_CONDUCT.md)

Drag'n Washは、物語のある一人称の洗浄ゲームです。

プレイヤーは洗い場を切り盛りするコボルドで、お客である3匹のドラゴンとは、
レベルが進むにつれて親しくなっていきます。

ここは、それを十数の言語の人たちが自分の言葉に移している小さなプロジェクトです。

そういう場所として扱ってください。

## お願いしたいこと

- **親切に。相手には悪気がないと考えて**:
  ここにいるほぼ全員が、空いた時間に、楽しみで、母語でない言葉を相手にやっています。
  書かれたものは、いちばん好意的に読めるかたちで読んでください。
- **はじめての人には気長に**:
  **「そもそもプルリクエストってどう出すの」**は、ちゃんとした質問ですし、列の順番が狂ったCSVもそう。
  いまここで訳している人はみんな、最初は何かしら間違えました。
- **批判は訳そのものに、具体的に**:
  **「ここのRyanはConradをからかっているから、丁寧語にはならない」**は、役に立ちます。
  **「あなたの英語は下手だ」**は、役に立ちません。
- **訳は判断であって、正解ではありません**:
  同じ言語の話者どうしが一行について意見を違え、どちらも正しいことがあります。
  争うなら、その行についてであって、どちらがより **「本物の話者」** かではありません。
- **引き際を受け取る**:
  その話はやめてほしい、その言い方はやめてほしいと言われたら、やめてください。

## やめてほしいこと

- **あらゆる嫌がらせ**:
  Issue、プルリクエスト、コミットメッセージ、コード、訳文、そのほかこのプロジェクトが届くどこであってもやめてください
- 書いたものではなく、その人自身に向けた侮辱・攻撃・国籍・言語・訛り・能力・性別・性的指向・信条・年齢・容姿についてのものを含みます。
  議論に勝つために **「あなたはネイティブではない」** と言うのも、ここに入ります。
- **人に向けた、望まれていない性的な言動**:
  ゲームは成人向けですから、CSVに露骨な台詞があることも、それをどう訳すかをまじめに話し合うことも仕事のうちです。
  文章にではなく協力者本人に向けた発言はそうではありませんし、関係のないスレッドにその調子を持ち込むのも同じです。
- **ゲームにないものを訳に紛れ込ませること**:
  侮蔑語、誰かを笑いものにする冗談、政治、宣伝、そのほか原文が言っていないこと。
  ゲームの言葉は、勝手に変えていいものではありません。
- **誰かの私的な情報を公開すること、またその示唆**
- **場を壊し続けること**:
  決着した議論の蒸し返し、スパム、レビューする人の時間をわざと浪費すること
- **ネタバレを、それを含むことになっている場所（CSVと、それについてのIssue）の外に書くこと**:
  Issueを読む人がみなクリア済みとは限りません。

## 適用される範囲

このプロジェクトが動くところすべてです。
Issue、プルリクエスト、Discussions、コミット、訳文そのもの、リリースノート、
そして誰かがこのプロジェクトやその参加者を代表して話している場所。

## 報告

誰かの振る舞いがおかしいときは、メンテナー（[@TomXV](https://github.com/TomXV)）に知らせてください。

- 公開の場に書きたくないことは、このリポジトリの **Security** タブにある
  非公開のフォーム（[**Report a vulnerability**](https://github.com/TomXV/dragnwash-localization/security/advisories/new)）
  を使ってください。
  本来はセキュリティ報告のためのものですが、このリポジトリにある非公開の窓口はこれで、届く先は同じ人です。
  冒頭に、セキュリティではなく行動についての報告だと書いてください。
- それ以外は普通のIssueで構いません。
- 問題がメンテナー自身にあるとき、あるいはまったく別の人に見てほしいときは、
  GitHub自身の[不適切な行為の報告](https://docs.github.com/ja/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
  を使ってください。
  GitHubの担当者はこのプロジェクトとは無関係です。

報告は非公開で読みます。
返事はします。何が起きたかによって、答えは一言の注意であったり、コメントの編集や削除、訳の差し戻し、スレッドを閉じること、
リポジトリからのブロックであったりします。
わざと嘘の報告をすることも、この文書に反します。
